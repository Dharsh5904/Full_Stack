# Simple Interest Calculator

A simple and responsive web-based calculator for calculating Simple Interest and Total Amount.

## Features

- Calculate Simple Interest
- Calculate Total Amount
- Responsive design
- Smooth animations
- Modern UI
- Reset functionality

## Formula

Simple Interest = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Interest Rate
- T = Time in Years

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Enter the Principal Amount, Interest Rate, and Time.
4. Click **Calculate**.
